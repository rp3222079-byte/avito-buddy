# Бадди · Avito Start

Локальный прототип на React, TypeScript и Vite. В чате с Бадди стажёр получает утренний брифинг и оформляет заявку на доступ. Наставник смотрит прогресс стажёров и согласует заявку. Прототип работает на демоданных.

## Запуск

Нужен Node.js 22.12+ (проверено на 24.21) и npm.

```sh
git clone https://github.com/rp3222079-byte/avito-buddy.git
cd avito-buddy
npm ci
npm run dev
```

Открой адрес из терминала, обычно http://127.0.0.1:5173. Приложение привязано к loopback. Учётная запись и ключи API не нужны. Для повторного открытия остановленного прототипа достаточно `npm run dev`.

```sh
npm run build
npm run preview
npm test
npm run test:coverage
```

Точные версии зависимостей закреплены в `package-lock.json`. Сборка находится в `dist/`. Запускай её через HTTP-сервер. Демо работает с локальными шрифтами, изображениями и данными.

На ноутбуке `npm run dev` запускает демо без backend. `npm test` проверяет сетевой адаптер на SSE-ответах и HTTP-статусах с подменой `fetch`.

Когда backend будет доступен, установи `VITE_API_MODE=real` перед запуском Vite или сборкой и настрой проксирование `/api` на том же origin. Чат по умолчанию использует `POST /api/chat`. Для другого пути задай `VITE_CHAT_PATH`. Формат SSE и тела POST-запросов описаны в [docs/integration-contract.md](docs/integration-contract.md).

## Демосценарий на 2 минуты

1. Нажми «Доступ к Jira» под чатом либо «Попросить Бадди помочь» в карточке квеста.
2. Бадди подготовит черновик. Нажми «Изменить данные», поправь основание и сохрани.
3. Нажми «Отправить заявку». Появится REQ-042 со статусом «Ожидает согласования». Опыт пока не начисляется.
4. Переключись на «Наставник» и нажми «Согласовать в демо». Квест завершится, будет начислено 120 XP.
5. Открой библиотеку или ссылку на инструкцию команды. Нажми «Прочитал, всё понятно»: ещё 100 XP, уровень 3, 3/3 квеста.
6. Перезагрузи страницу: переписка, заявка и опыт сохранятся в этом браузере.

В разделе «Помощь» можно включить однократный обрыв ответа или сбой отправки заявки. После обрыва нажми «Повторить отправку». При сбое заявки черновик сохраняется. Сброс демо доступен из меню профиля.

## Что работает

- Три квеста первой недели, независимое изучение инструкции, выбранный квест и следующий шаг.
- Чат со сценарными ответами: доступ к Jira, команда, наставник, следующий шаг, экватор, отказ для закрытых сведений и отсутствие ответа в тестовой базе.
- Заявка: черновик → отправка → ожидание → демосогласование. Повторный запрос не создаёт дубликат; повторное завершение не начисляет XP.
- Библиотека, тестовые инструкции, карточка команды и информация о будущем боссе «Экватор».
- XP и уведомление о новом уровне, сохранение localStorage, восстановление повреждённых данных и уведомление при недоступном хранилище.
- Мобильные вкладки, клавиатурное управление, нативные диалоги с ограничением фокуса, поддержка reduced motion.

Босс представлен карточкой подготовки: боевой механики, проверки презентаций и перехода к новым главам здесь нет. Начальный прогресс намеренно задан демоданными: знакомство с командой выполнено, Роман на уровне 2. Интерфейс не подтверждает реальные права пользователя; серверная авторизация будет отдельным этапом.

## Структура

- `docs/project-context.md` — требования трека, решения из обсуждения, роли команды и оставшиеся этапы.
- `src/model.ts` — демоданные, типы, состояния и переходы, ответы, расчёт опыта, сохранение.
- `src/App.tsx` — роли, переписки, навигация и пользовательские действия.
- `src/api.ts` — демопоток и GET-адаптеры backend.
- `src/ChatMessage.tsx` и `src/ChatInput.tsx` — сообщения, Markdown, действия и форма чата.
- `src/Modal.tsx` — доступное диалоговое окно.
- `src/styles.css` — оформление и адаптивность.
- `src/*.test.*` — тесты поведения и компонентов.
- `docs/behavior.md` — спецификация взаимодействий и критерии готовности.
- `docs/integration-contract.md` — предлагаемые границы будущей интеграции для обсуждения с командой.
- `public/assets` — подготовленная комната и выбранный маскот.
- `design/concepts` — визуальные концепты и промпты.

## Проверка

Шаблон GitHub Actions сохранён в `docs/ci.yml.example`. Для включения перенесите его в `.github/workflows/ci.yml` через GitHub или с токеном с правом `workflow`. Текущая авторизация не позволяет публиковать workflows, поэтому CI пока не активен.

`npm run test:coverage` создаёт `coverage/index.html` и `coverage/coverage-summary.json`. Проверяются полный путь заявки, редактирование, отказ сервиса и повтор, отсутствие дубликатов, XP, восстановление, источники и диалоги. Минимальный порог строк и statements — 81%. Стили, графические файлы и bootstrap `src/main.tsx` исключены из метрики прикладной логики; качество вёрстки проверяется отдельно в браузере.

## Дизайн

Композиция основана на выбранной «Комнате Бадди», маскот — проводник. Кнопки и тексты реализованы как HTML, иллюстрация комнаты — отдельный PNG. Четыре цвета Avito адаптированы под спокойную тёмную палитру; это концепт команды, не официальный брендбук. Новая иллюстрация комнаты создана встроенным image_gen; её запрос сохранён в `design/concepts/room-asset-prompt.md`.
