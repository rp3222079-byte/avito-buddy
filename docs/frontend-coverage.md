## Область и воспроизведение

В отчёт входят TypeScript и TSX из `src/`. Из расчёта исключены тесты, их настройка и `src/main.tsx`. Общие модули приложения, в которых реализованы mock- и real-сценарии, учтены целиком. Данные имитаций из `data/` вне области измерения. Покрытие Go API, AI-сервиса и RAG в эти цифры не входит. [Конфигурация Vitest](../vite.config.ts)

```sh
npm ci
npm run test:coverage
```

Тесты интерфейса запускаются в mock-режиме независимо от локального `.env`. Тесты real-адаптера включают real-режим отдельно и подменяют сетевые ответы. Подробный HTML-отчёт создаётся в `coverage/index.html`, машиночитаемая сводка — в `coverage/coverage-summary.json`.
