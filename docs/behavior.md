# Спецификация поведения фронтенд-демо

Статус: реализовано. Цель — дать стажёру понятный путь от вопроса до сохранённого результата. Все личности, процессы и ответы синтетические. Это спецификация демоповедения, не описание реализованного LLM-агента.

## Стартовые данные

Роман, Backend, наставник Анна Соколова. Квест «Знакомство с командой» завершён (80 XP). Базовые 160 XP дают суммарно 240 XP и уровень 2. Заявки нет. Бадди приветствует Романа и предлагает запросить доступ либо открыть библиотеку.

Уровень = floor(XP / 200) + 1. Шкала отображает прогресс внутри текущего уровня, подпись — суммарный опыт и следующий порог. Квест доступа даёт 120 XP только после демосогласования. Изучение инструкции — 100 XP только по явному нажатию «Прочитал, всё понятно». Награда каждого квеста выдаётся однократно.

## Экран и навигация

| Элемент | Поведение |
| --- | --- |
| Логотип | Возвращает к комнате и выбирает квест доступа |
| Квест слева | Выбирает задачу; центральная карточка показывает её статус, описание и действие |
| Библиотека | Открывает список из двух тестовых инструкций |
| Мои квесты | На узком экране открывает вкладку квестов; на широком выбирает доступ и подсказывает смотреть список слева |
| Экватор / будущий босс | Показывает требования подготовки и явно сообщает, что прохождение босса не реализовано |
| Карточка команды | Информация о вымышленном наставнике и ссылка на инструкцию |
| Демо-мир | Инструкция прохождения и переключатель единичного сбоя сервиса |
| Сброс | Подтверждение → очищение только состояния этого приложения и возврат стартовых данных |

Ширина до 760 px: вкладки «Квесты», «Комната», «Бадди», активна одна панель. Отправка запроса переключает на чат. Диалоги закрываются крестиком, Escape или нажатием на фон. Нативный dialog удерживает клавиатурный фокус, после закрытия фокус возвращается.

## Чат

- Enter отправляет непустое сообщение, Shift+Enter оставляет перенос строки. Максимум 500 символов.
- Пользовательское сообщение появляется сразу, индикатор ожидания — на 650 мс, затем подготовленный ответ.
- На время ожидания отправка и изменение заявки заблокированы. В интерфейсе явно указано «Демоответы · без LLM».
- Локальная маршрутизация поддерживает вопросы о доступе/Jira/заявке, инструкциях/команде, наставнике, следующем шаге, экваторе и приветствия. Неподдерживаемый вопрос получает честный ответ о границах базы и предложение обсудить вопрос с Анной.
- Запрос чужих/финансовых/закрытых сведений получает отказ. Это демонстрационная реакция по ключевым словам, не механизм авторизации.
- Источники открывают настоящие текстовые диалоги. Инструкции явно помечены тестовыми.

## Жизненный цикл заявки

| Исходное состояние | Действие | Результат |
| --- | --- | --- |
| Нет заявки | Запрос доступа | Черновик на Jira с основанием и командой Backend |
| Черновик | Изменить | Диалог; основание 5–240 символов, Jira и команда фиксированы |
| Черновик | Отправить | 900 мс ожидания, блокировка повтора, затем REQ-042 со статусом ожидания |
| Черновик, включён сбой | Отправить | Сообщение ошибки, черновик сохранён, награда отсутствует; флаг сбоя сбрасывается |
| Ошибка | Повторить отправку | Тот же единственный запрос переходит в ожидание |
| Ожидание | Согласовать в демо | Статус «Доступ выдан», квест завершён, +120 XP |
| Любая существующая заявка | Повторный вопрос | Текущий статус, без новой заявки |
| Уже завершено | Повтор действия | Без повторного XP |

Создание заявки не завершает задачу доступа. Библиотека и квест инструкции доступны независимо от согласования. Реальные корпоративные операции не выполняются.

## Сохранение и устойчивость

localStorage key: `avito-buddy-demo-v1`. Сохраняются завершённые квесты, заявка и до 60 сообщений. Карточка заявки остаётся доступна даже после обрезки старой переписки. XP выводится из завершённых квестов, отдельной изменяемой копии нет.

Перед чтением проверяются версия, типы и согласованность статуса доступа. Повреждённые или недоступные данные заменяются стартовым состоянием. Если запись запрещена/не хватает места, интерфейс продолжает работать в памяти и сообщает, что прогресс не сохранён.

При перезагрузке в момент отправки остаётся черновик: реального внешнего действия нет. При сбросе таймеры отменяются, отложенный ответ не попадает в новое приключение.

## Критерии приёмки

1. Можно пройти черновик → редактирование → ожидание → согласование без сервера.
2. XP не меняется до подтверждённого завершения; после доступа и инструкции — 460 XP / уровень 3.
3. Перезагрузка сохраняет заявку, переписку, квесты и уровень.
4. Ошибка отправки сохраняет введённые данные и позволяет повторить действие.
5. Повторные нажатия и запросы не создают дополнительные заявки или XP.
6. Источники, библиотека, наставник и босс открываются; тестовый характер данных виден.
7. На настольном и узком экране доступны чат, задачи и комната; нет горизонтального переполнения.
8. Сборка и автоматизированные тесты проходят, покрытие строк прикладного TS/TSX-кода превышает 80%.
