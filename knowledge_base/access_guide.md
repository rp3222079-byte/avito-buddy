# [ТЕСТОВЫЙ МАТЕРИАЛ. НЕ РЕГЛАМЕНТ АВИТО]

## 1. Базовые доступы (1-й день)
- Почта, внутренний мессенджер и Jira выдаются автоматически в первый рабочий день.
- Если почта не работает, обратитесь в IT-поддержку через специальный бот.

## 2. Запрос доступов (Confluence, GitHub, Figma)
- **Confluence (База знаний):** Для доступа необходимо создать заявку через IT-портал. Срок выдачи — до 2 часов. Самостоятельно просить наставника не нужно, он не имеет прав администратора.
- **GitHub (Репозитории):** Доступ к коду запрашивается у тимлида команды лично в чате. Необходимо указать свой никнейм на GitHub и название репозитория.
- **Figma (Дизайн-система):** Для доступа к макетам фронтенд-стажерам нужно запросить доступ через IT-портал. В заявке указать "Дизайн-система Авито".

## 3. Что делать, если доступ не пришел через 4 часа?
- Напишите в чат IT-поддержки, приложив номер заявки. 
- Не пишите наставнику с просьбой ускорить процесс. Наставник не может повлиять на работу IT-департамента. 

## 4. Рабочее окружение (Backend)
- Основной язык: **Go**. Для ML-задач используется **Python**.
- Базы данных: **PostgreSQL** (основная), **Redis** (кэш).
- Для запуска проекта локально используется **Docker**. Все инструкции по запуску лежат в README.md в корне репозитория.
