# [ТЕСТОВЫЙ МАТЕРИАЛ. НЕ РЕГЛАМЕНТ АВИТО]

## Неделя 1: Знакомство и настройка
- [ ] Получить ноутбук и настроить VPN.
- [ ] Запросить доступ к Confluence (база знаний).
- [ ] Запросить доступ к GitHub (репозитории).
- [ ] Познакомиться с командой на общем созвоне.
- [ ] Прочитать раздел Playbook "Инженерные практики" и "Как мы пишем код".
- [ ] Провести первую встречу 1:1 с наставником.

## Неделя 2-4: Первые задачи
- [ ] Взять первую задачу из Jira (с тегом `good-first-issue`).
- [ ] Пройти код-ревью от старшего разработчика.
- [ ] Запросить доступ к дизайн-системе (для фронтендеров).
- [ ] Внести свои цели и задачи в инструмент отслеживания прогресса стажера.

## Месяц 3: Экватор
- [ ] Пройти онлайн-курс по публичным выступлениям (рекомендация от HR).
- [ ] Подготовить презентацию с промежуточными результатами.
- [ ] Согласовать презентацию с наставником.
- [ ] Выступить на экваторной встрече.
- [ ] Получить обратную связь от руководителя.

## Месяц 6: Выпускной
- [ ] Закрыть все ключевые задачи по OKR.
- [ ] Пройти финальное ревью компетенций.
- [ ] Заполнить опрос о качестве стажировки.
